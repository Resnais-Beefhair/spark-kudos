# KUDOS 0.5.0

First public release of a configurable, read-only operations dashboard for one or two NVIDIA DGX Spark systems. The 0.5.x series is beta software.

## Highlights

- Standalone Linux/Python collectors for CPU, unified memory, network, mounted storage and declared services.
- Optional second host over an existing, verified, read-only SSH route.
- Strict TOML configuration for host labels, roles, paths, interfaces, volumes, services and integration flags.
- English-default UI and documentation, with a full Finnish UI choice persisted in the browser.
- Bounded live updates, independently fresh host panels, resource drilldowns and in-memory history.
- Optional agent, cron, quota, resource-registry and privacy-filtered log adapters, disabled by default.
- Loopback binding by default. No automatic service control, GPU driver polling or private-source discovery.

## Install

Requires Linux and Python 3.12 or later. Download the wheel attached to the GitHub release, then run:

```bash
uv tool install ./sisu_kudos-0.5.0-py3-none-any.whl
sisu-kudos --version
sisu-kudos
```

Or clone [the repository](https://github.com/Resnais-Beefhair/spark-kudos) and follow the [README](https://github.com/Resnais-Beefhair/spark-kudos/blob/main/README.md). No PyPI publication is assumed. The package and command are named `sisu-kudos`; the product is **KUDOS**.

## Important boundaries

GPU readings require an existing compatible shared JSON telemetry producer. KUDOS does not install a producer, run NVML/nvidia-smi, change clocks or manage a thermal guard. A missing measurement is unknown, not zero.

The dashboard has no built-in authentication and is not safe to expose directly to the internet. Use the default loopback listener with an authenticated HTTPS reverse proxy or an SSH tunnel. Review the [security policy](https://github.com/Resnais-Beefhair/spark-kudos/blob/main/SECURITY.md) before deployment.

The base install does not need any agent software or private repositories. Optional legacy adapters may require separately configured, operator-owned sources. Existing private installations are not automatically migrated.

## Verification

Before publication, the source passed 231 regression tests on Python 3.12 and 3.14, lint, package/build checks and isolated synthetic browser QA. Clean-wheel integration checks exercised one host, two real Sparks, and a controlled remote failure without blocking local collection. Screenshots contain explicitly synthetic data. Hosted CI results are shown on the repository's Actions page; local results are not a substitute for that status.
