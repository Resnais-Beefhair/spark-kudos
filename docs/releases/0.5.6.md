# KUDOS 0.5.6

A denser operations view and optional Claude subscription usage. This release includes
the previously unpublished 0.5.2–0.5.5 development changes. Existing configurations
remain compatible; the new provider integration is disabled by default.

## Changes

- Work cards use two content lines on desktop. Agent, runtime, state, elapsed time,
  task and origin stay visible; narrow screens give task and origin separate lines.
- Model, reasoning level, Fast mode and the exact tool name are available in the
  card's detail dialog. Release QA caught and fixed missing reasoning/Fast fields.
- Activity glyphs remain on each card, with tooltip captions and reduced-motion support.
- The capacity strip uses tighter spacing, side-by-side Claude tracks, and complete
  reset timestamps. Tablet and mobile layouts remain responsive.
- Optional, independent Claude subscription usage shows five-hour and aggregate weekly
  windows, using an existing local Claude Code login without modifying it. See
  [the integration and privacy guide](../CLAUDE-QUOTA.md).
- Failed usage refreshes retain last-confirmed values as stale. A usage-query rate
  limit is explicitly distinct from exhausting the subscription itself.

No additional runtime dependency, authentication layer or network exposure is added.
KUDOS remains read-only and Linux-focused.

## Installation and upgrade

Download the wheel and `SHA256SUMS` from this release. Check the checksum first, then:

```bash
uv tool install --upgrade ./sisu_kudos-0.5.6-py3-none-any.whl
sisu-kudos --version
sisu-kudos --config /path/to/kudos.toml --check-config
```

Restart your own dashboard only when you intend to deploy the upgrade. To enable
Claude usage, explicitly configure `integrations.claude_quota = true`; upgrading alone
does not read credentials or contact Anthropic.

Do not expose the unauthenticated listener directly. Use an authenticated HTTPS
reverse proxy or an SSH tunnel for remote access.

## Verification

Tests cover provider parsing, credential/payload allowlists, disabled integration,
rate limits, stale-data retention, failure recovery and independent scheduling.
Synthetic Chromium QA exercises both UI languages, five simultaneous work cards at
1920/1440/1366/1024/768/390 px, compact heights, text collisions, details and keyboard
focus, alongside quota, host and failure-path regressions under the application CSP.

Release assets are an installable wheel, Python source distribution, complete source
ZIP and `SHA256SUMS`. Production captures and private configuration are excluded.
No PyPI publication.
