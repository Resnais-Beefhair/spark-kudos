# KUDOS 0.5.1

A small corrective release following the first public audit. Configuration and the
read-only telemetry contract remain compatible with 0.5.0.

## Fixes

- Missing ChatGPT quota information no longer sends a Finnish fallback from the
  backend. Both the summary and quota inspector use the selected UI language.
  Source-provided plan names and diagnostic text remain unchanged (#1).
- Empty host-disk lists now render real, localized DOM text instead of Finnish CSS
  generated content. Switching language and recovery to populated lists are tested (#2).
- Successful cron health messages are empty and language-neutral. Failures still
  report only bounded, sanitized diagnostics (#3).
- CSP additionally blocks framing, base-URL overrides and form submission. Existing
  same-origin resource restrictions and X-Frame-Options remain in place. This is
  defense in depth, not a claim of a newly discovered exploitable vulnerability (#4).
- Process CPU/I/O history belongs to each collector instance, avoiding cross-app
  samples. Event filtering now matches the agent-only event allowlist; cron runs
  remain in their separate ledger. A duplicate import was removed and remote Linux
  paths now use explicit POSIX semantics, independent of the local developer OS (#5).

The remote-path improvement does not add Windows runtime support; KUDOS targets Linux.
No authentication, network exposure, dependencies or configuration fields changed.

## Installation and upgrade

Download the wheel and `SHA256SUMS` from this release. Check the checksum first, then:

```bash
uv tool install --upgrade ./sisu_kudos-0.5.1-py3-none-any.whl
sisu-kudos --version
sisu-kudos --config /path/to/kudos.toml --check-config
```

Restart your own dashboard only when you intend to deploy the upgrade. Existing
configuration is compatible. Do not expose the unauthenticated listener directly;
use an authenticated HTTPS reverse proxy or an SSH tunnel for remote access.

## Verification

Synthetic regression tests reproduce the previous behavior before the fixes, including
cross-app process-counter leakage and remote-path validation with Windows semantics.
Browser QA checks English/Finnish quota summary and inspector text, missing disks,
language switching, disk recovery, dialog focus, remote failures and mobile overflow
under the actual application CSP. Tests do not require production telemetry or SSH.

Release assets: installable Python wheel, Python source distribution, complete project
source ZIP and `SHA256SUMS`. No PyPI publication.
